# CMPM-125-Final-Project

## Unity version 6000.3.14f1. 
Currently expanding the level design and improving the robot's abilities.

**Controls**
  - WASD: Move
  - Mouse: Aim
  - Space: Jump 
  - Hold Left Click: Pull and hold targeted object
  - Release Left Click: Drop mouse held object
  - Right Click: Throw held object
  - E: Grab and drop targeted object
  - F: Throw held object
  - R: Return scrap to the current recovery point

Keyboard and mouse interaction controls can be used together
